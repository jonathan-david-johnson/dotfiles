# Exclusion patterns for the borg-mac backup, per TIMEMACHINE_TO_BORG_SPEC.md section 6.
# Passed to `borg create --exclude-from`.
#
# Patterns are prefixed with **/ deliberately: the backup source is a mounted
# snapshot (e.g. /tmp/borg-mac-snapshot/Users/jdj/...), so a pattern anchored
# at "Users/jdj/..." does NOT match — the actual stored path starts with the
# mount prefix. Confirmed 2026-09-12: with un-prefixed patterns, every
# exclusion silently failed to match and Google Drive/iCloud/FileProvider
# content was walked in full (causing most of that run's cloud-placeholder
# timeouts and permission-denied warnings). **/ matches any number of leading
# path segments, so this works regardless of the mount path.
#
# Every entry here costs restore completeness. See the spec for the reasoning
# behind each one before adding more.
